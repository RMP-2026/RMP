RMP (Rental Market Place) — Complete Mobile UI Design System

Design the complete UI/UX for RMP (Rental Market Place). RMP is a premium B2B marketplace where rental companies own fleets, manage pricing, and manage insurance. Customers browse nearby verified companies and request bookings. This is NOT Turo.

Style: Premium Luxury, Dark Theme, Glassmorphism, Minimal, Apple Human Interface. Inspired by Stripe, Linear, Airbnb, Rivian, and Tesla. Large spacing, 20px rounded corners, soft shadows, beautiful typography, clean hierarchy, highly readable, developer-ready.

Technical constraints:

React 19 + Vite + Tailwind CSS v4
All styling via inline CSS style={{}} props exclusively — zero Tailwind utility classes
No external chart libraries — use pure SVG <polyline>/<polygon> with <linearGradient> for line/area charts, and flex divs with percentage heights for bar charts
No framer-motion, no recharts, no mapping libraries
Google Fonts Inter — @import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800;900&display=swap') must be the absolute first line in index.css before @import 'tailwindcss'
Unsplash images via https://images.unsplash.com/photo-{id}?w={width}&h={height}&fit=crop&auto=format
useState for interactive calendar date selection

PhoneFrame component: 290×600px, borderRadius 44, background #080C14, border 1.5px solid rgba(255,255,255,0.11), boxShadow 0 32px 80px rgba(0,0,0,0.7). Dynamic island is a 90×28px black pill centered at top (position absolute, top 12, borderRadius 14, background #000, zIndex 20) — NOT a notch. Status bar shows "9:41" time left-aligned with signal/wifi/battery icons right-aligned, all in white, below the dynamic island. Each PhoneFrame receives a label prop rendered as a caption below.

Canvas layout: Dark canvas #050709, padding 60px 80px 80px. Each board is a <section> with a BoardLabel showing board number, title, and screen count. Phones arranged in flexWrap: "wrap", gap: 32. Boards separated by marginBottom: 100.
